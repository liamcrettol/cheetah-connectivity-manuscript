# Table-source provenance

Every number in a manuscript table comes from one of these files. Never copy a number
from a screenshot, a map legend, or memory.

## Two traps to avoid

- `SUPERSEDED_table_protected_area_coverage_20260909_084224.csv` is the OLD protected-area
  result. It includes the cores, so it reports different numbers (for example 27.6
  percent protected at the 99th percentile, where the paper says 44.63). Do not cite it.
  The paper uses `outside_core_current_pa_curve_20260909_153100.csv`. The old file is
  kept only so the history is visible.
- In `table_primary_priority_links_20260909_084224.csv`, the column
  `prior_temporal_interpretation` comes from an earlier run. For four links it points the
  wrong way: 30--40, 40--42, and 28--33 say "decreasing" but the final change is an
  increase, and 45--50 says "increasing" but the final change is a small decrease. Always
  use `final_effective_resistance_change_percent_2012_2024` for direction.
